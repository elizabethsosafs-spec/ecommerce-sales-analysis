## 📊 Project Overview

## 📊 Project Overview

This project analyzes e-commerce sales and customer behavior data to identify sales trends, customer patterns, and factors that may influence purchasing activity.

The project combines **Excel** for data analysis and exploratory work with **Power BI** for interactive data visualization and dashboard development.

The objective is to transform raw transactional data into clear and actionable business insights.

---

## 🎯 Business Questions

The analysis focuses on questions such as:

* How do sales evolve over time?
* Which product categories generate the most sales?
* Which categories sell the most units?
* How do new and returning customers compare in terms of sales?
* Which cities generate the highest sales?
* How do different discount ranges relate to sales?
* Which payment methods are most frequently used?
* How does session duration relate to customer activity?
* How are customer ratings distributed?
* Which devices are most commonly used for purchases?

## 🔎 Key Insights

Some of the main findings from the analysis include:

* **Electronics** is the highest-revenue product category.
* **Sports** records the highest number of units sold.
* **Mobile** is the most frequently used device for purchases.
* **Credit Card** is the most frequently used payment method.
* The dataset contains **5,000 orders** and more than **11,000 units sold**.
* The overall **Average Order Value is 983.11**.

These insights provide a starting point for understanding customer purchasing behavior and overall e-commerce performance.
